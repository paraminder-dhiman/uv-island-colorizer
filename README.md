# UV Island Colorizer

A Blender add-on that gives every UV island its own random color and can bake the result to a color ID map.

## What it does

- Add meshes from a picker, from the viewport selection, or from a whole collection
- Color every UV island on each mesh in one click
- Optionally bake each mesh to a PNG, from 64 to 8192 px
- Bake settings are kept between Blender sessions

Islands stacked exactly on top of each other in UV space share one color.

## Install

1. Download the zip from the latest release
2. In Blender, open Preferences and use Install from Disk
3. Open the sidebar in the 3D viewport and find the UV Island Colorizer tab

The panel has a Help button that explains each step.

## Requirements

Blender 4.2 or newer. Tested on Blender 4.2 LTS and 5.2 LTS.
